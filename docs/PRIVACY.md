# 隐私说明 / Privacy

**一句话：这个工具没有服务器。你输入的一切都在你自己的浏览器里，刷新就没了。**

## 数据流向

```
你的输入  →  浏览器内存  →  渲染在屏幕上
                ↓
            （结束）
```

没有第二步。代码里没有把数据送出去的能力：

- 没有 `fetch`、`XMLHttpRequest`、`WebSocket`、`EventSource`、`sendBeacon`
- 没有第三方脚本、统计 SDK、广告、A/B 测试、错误上报
- 没有外部字体、外部图片、CDN、favicon 远程地址
- 没有 `localStorage`、`sessionStorage`、`IndexedDB`、Cookie

上面这些不是承诺，是可以用一条命令自己验证的：

```bash
node scripts/check-no-network.mjs   # 退出码 0 = 通过
```

它会真的读每一个文件、报出文件与行号。我们也把一行 `fetch` 故意注入进去验证过它确实会失败（见 `work/qa/` 的报告）。

## 你不输入，它就不存在

工具**不要求**你填任何真实信息：

- 方案名称可以写"方案 A / 方案 B"，或者"那个选项"
- 因素名称可以用默认的
- 不需要邮箱、手机号、账号、位置、设备信息

## 导出与分享

| 动作 | 发生在哪里 | 会不会外发 |
|---|---|---|
| 导出 JSON | 浏览器本地 `Blob` + `a[download]` | 不会 |
| 导入 JSON | 浏览器 `FileReader` 读本地文件 | 不会 |
| 打印 / 存 PDF | 浏览器打印对话框 | 不会 |
| 分享摘要 | 生成一段文字放到 `<textarea>`，你自己按复制 | 不会 |

**分享摘要默认不包含你写的方案名称。** 摘要里只有得分、因素名称和那条反转条件。
复制之前，文本框里的内容会先给你看一遍，确认没问题再复制。

如果分享摘要里还是出现了你不想公开的东西，直接关掉对话框即可，不会留下任何记录。

## 部署到 GitHub Pages 后呢

GitHub Pages 会记录访问日志（IP、User-Agent），这是 GitHub 作为托管方的行为，不是本工具的代码行为。
本工具的静态文件里没有任何东西会主动上报。如果你对此有顾虑，可以把 `site/` 整个目录下载下来，
用 `node scripts/serve.mjs` 在本地打开，完全离线使用。

## 清除数据

没有需要"清除"的持久数据 —— 刷新页面就清空了。
"清空重来"按钮做的是重置页面内存里的表单状态。

## 如果你 fork 了这个项目

请保持以上性质。任何引入网络请求、遥测或持久化的改动都会让这份隐私说明变成谎话，
请在 PR 里同时更新本文件，并跑 `node scripts/check-no-network.mjs`。
