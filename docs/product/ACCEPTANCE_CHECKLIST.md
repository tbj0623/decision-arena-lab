**B-15 回归用例**（`site/core.mjs` 19:05 版本已把越界判断置于边界判断之前，此条用于防回退）

t\* < 0 的真实含义是"即使把该因素权重压到 0 也不会翻转"，与 t\* 正好落在 0/1 边界（`BOUNDARY`）是两件事，两者文案不能混。执行：

```bash
node -e "import('./site/core.mjs').then(({findFlipThresholds})=>{
const d={options:[{label:'甲'},{label:'乙'}],factors:[
 {id:'f1',label:'强A',weight:5,ratings:{A:9,B:2}},
 {id:'f2',label:'中B',weight:3,ratings:{A:2,B:9}},
 {id:'f3',label:'中性',weight:2,ratings:{A:5,B:5}},
 {id:'f4',label:'弱A',weight:1,ratings:{A:10,B:0}}]};
const t=findFlipThresholds(d).find(x=>x.factorId==='f4');
console.log(t.code, t.thresholdShare.toFixed(4), t.explanation);
if(t.code!=='OUT_OF_RANGE'){process.exit(1)}})"
```

期望输出：`OUT_OF_RANGE -0.1628 临界点落在 0–1 之外：…结果不会翻转。` 且退出码 0。
同批次 `f3`（`t* = 1`）应为 `BOUNDARY` —— 两条必须不同。

**B-17 判别用例**（差值取整陷阱，实测 `scoreA = 46.666…`、`scoreB = 53.333…`）

