# 反悔雷达 · Decision Arena

> **不是替你预测未来，而是找出什么条件会改变你的选择。**

一个开源、免费、无需登录的浏览器端决策敏感性分析工具。你给两个犹豫中的方案打分，
调一调你在意的权重，它会告诉你：现在的倾向有多稳、**哪个因素的权重一旦改变结论就会翻过来**、
以及你最该先去核实哪一条假设。

**它不是**成功率计算器，不是预测模型，不是 AI 算命，也不提供任何专业建议。
分数完全来自**你自己打的分数和你自己设的权重**。

## 快速开始（零依赖）

```bash
git clone <this-repo>
cd decision-arena-lab

# 1) 跑算法单测（只需要 Node ≥ 18，不装任何依赖）
node --test

# 2) 本地打开网站（必须走静态服务器，见下方说明）
node scripts/serve.mjs        # 然后打开 http://127.0.0.1:8080
```

> **⚠️ 直接双击 `site/index.html` 打不开。** 本站用原生 ES Module（`<script type="module">`），
> 浏览器的 CORS 策略会拒绝 `file://` 协议下的模块加载，页面会显示空白。
> 这是浏览器的安全限制，不是本站的缺陷，也不会为它加打包步骤。
> **请用 `node scripts/serve.mjs` 起本地静态服务器**——它只用 Node 内置 `http`，
> 不装依赖、不联网、不写磁盘，零配置。

> **测试命令说明**：Node 24 里 `node --test tests/` 会把目录当成模块去解析然后报
> `MODULE_NOT_FOUND`。请用**无参数**的 `node --test`（让它自动发现 `**/*.test.mjs`），
> 或者用 glob：`node --test "tests/**/*.test.mjs"`。

## 它做什么

| 步骤 | 你要做的 | 工具给你什么 |
|---|---|---|
| 1 | 写两个方案的名字 | — |
| 2 | 列出 4–6 个你在意的因素 | 可增删、可改名 |
| 3 | 给每个因素的两个方案打 0–10 分 | 打分按钮 + 数字输入，键盘可用 |
| 4 | 调每个因素的权重（0–10） | 实时重算 |
| 5 | 看结果 | 双方加权得分（0–100）、差值、贡献拆解表 |
| 6 | 看敏感性 | 每个因素的**反转阈值**：把它调到多少会打平、越过多少会翻转 |
| 7 | 拿到下一步 | 最该被核实的一条假设 + 一个 7 天内可完成的小动作 |
| 8 | 留存 | 导出 JSON、导入 JSON、打印、匿名分享摘要 |

## 算法（全部公开，可以自己验算）

设两个方案 `A`、`B`，因素 `i = 1..n`（4 ≤ n ≤ 6），

- `r_A[i]`, `r_B[i]` ∈ [0, 10] — 你打的**主观**分
- `w[i]` ≥ 0 — 你设的重要性权重

**归一化权重**：`p[i] = w[i] / Σw`

**得分**：`S(A) = 10 × Σ p[i]·r_A[i]`，范围 0–100。（B 同理）

**差值**：`Δ = S(A) − S(B)`。`|Δ| < 1e-9` 视为打平，不让浮点误差决定胜负。

**单因素反转阈值**：把因素 `k` 的权重占比设为 `t`，其余因素按原相对比例分剩下的 `1−t`。

```
d_k      = r_A[k] − r_B[k]
d_others = Σ_{i≠k} w[i]·(r_A[i] − r_B[i]) / Σ_{i≠k} w[i]
Δ(t)     = t·d_k + (1−t)·d_others
t*       = −d_others / (d_k − d_others)          ← Δ(t*) = 0
```

`t*` 是**打平点**。只有当 `d_k ≠ d_others`、其他因素权重 > 0、且 `0 < t* < 1` 时，
它才是可行区间内的合法临界点；要真正翻转必须**越过**它。

如果所有因素的评分差同号，那么不管怎么调单个因素的权重都翻不过来 ——
这时工具会直接说"翻不过来"，而不是编一个数字。

**不确定性**：工具**不**假装知道你不确定什么。它只按"哪个因素对当前差距贡献最大"
挑出一条最值得核实的假设，并明确标注这是启发式提示，不是对现实不确定性的测量。

## 隐私

- **没有服务器、没有数据库、没有后端**。就是几个静态文件。
- **没有第三方脚本**：没有统计、没有广告、没有 CDN、没有外部字体、没有外部图片。
- **不上传任何东西**：代码里没有 `fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon`。
- **不持久化**：不写 `localStorage` / `sessionStorage` / `IndexedDB` / Cookie。刷新即清空。
- 导出与分享都由浏览器本地生成。分享摘要默认**不包含你写的方案名称**。

详见 [docs/PRIVACY.md](docs/PRIVACY.md)。

---

## 局限（请务必读）

- 输入是你此刻的**主观**判断。工具无法判断你的评分是否属实。
- 输出只是"你的判断在你给的权重下的一致性"，**不是**客观最优、不是概率、不是预测。
- 阈值分析只考察"调整单个因素权重"这一种受控改动；同时改动多个因素不在此模型内。
- **不适用于**医疗、法律、财务、危机处置等高风险决定。这类决定请咨询有资质的专业人士。
- 工具的"三个视角"是**规则模板生成的文字**，不代表任何专业人士的意见。

详见 [docs/LIMITATIONS.md](docs/LIMITATIONS.md)。
