# 反悔雷达 / Decision Arena：零依赖的决策敏感性工具

给两个方案打分、给因素设权重，它算出加权得分，然后回答：**哪个因素的权重一变，结论就翻过来**。公式公开可验算。

**为什么零依赖**：没有 `package.json`、没有构建步骤，浏览器直接跑 ES Module。所以能离线审计（`check-no-network.mjs` 逐文件扫 `fetch`/`XHR`/`localStorage` 并报行号）、十年后还能打开、部署就是把 `site/` 丢到静态托管。

**为什么不用在线 API**：输出必须完全由你的输入决定。接了大模型就有说不清的黑箱：凭什么给建议、有没有看到数据。这里只有四则运算和一次一元方程求解，一次完整分析约 0.017ms。没有 API，就没有上传与账号。

**为什么算法和 UI 分离**：`core.mjs` 是纯函数不碰 DOM，Node 里可直接 import 测试；`app.mjs` 只做事件与渲染。`node --test` 一条命令跑完全部断言，UI 改版不会改掉数学。

**四个核心导出**：

- `scoreDecision(raw)`：返回 0–100 得分、差值、胜方、接近度和每个因素的贡献拆解。
- `findFlipThresholds(raw)`：解出每个因素的打平点 `t*`，给方向、距离和 `FEASIBLE`/`BOUNDARY`/`OUT_OF_RANGE`。翻不过来时直说。
- `projectAtShare(raw, factorId, t)`：把某因素占比设为 `t`、其余按原比例分配后重算。界面那根滑杆调的就是它。
- `chooseValidationHypothesis(raw, analysis)`：按"对当前差距贡献最大"挑一条最该核实的假设，并声明这是启发式。

**边界**：每个 0–100 的数字都来自**你自己的打分和你自己设的权重**，只是加权平均再乘 10。它**不是成功率、不是预测**。医疗、法律、财务等高风险决定**不适用**，请找有资质的专业人士。

**怎么跑**：

```bash
node --test                        # 单测，无参数自动发现
node scripts/check-no-network.mjs  # 静态扫描网络/持久化 API
node scripts/serve.mjs             # 本地预览 :8080
```

Node 24 下 `node --test tests/` 会把目录当模块解析并报错，用无参数形式。

**怎么贡献**：四条底线——不引入框架或第三方运行时依赖；新数学先进 `core.mjs` 并配单测；不加网络请求、遥测、持久化；不把产品描述成预测或专业建议工具。
